==============================================================
  PrivaCare-AI -- Experiment Results
  Model    : Logistic Regression
  Mechanism: Diffprivlib Objective Perturbation (replaces Gaussian)
  DP Type  : pure epsilon-DP  (NO delta needed)
  Dataset  : 6,000 rows | 13 features | 4 classes
  Trials   : 3 runs per epsilon (mean +/- std reported)
==============================================================

  HOW TO RUN
  ----------
    python models/lr_gaussian.py
    (Enter epsilon value when prompted)

  NOTE ON MECHANISM:
    We replaced the manual Gaussian Input Perturbation with IBM
    diffprivlib's LogisticRegression (Objective Perturbation).
    However, because Logistic Regression noise scales with L2 data_norm (3.605),
    it fundamentally underperforms Random Forest on this dataset.
