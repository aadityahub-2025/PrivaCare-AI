========================================================
  PrivaCare-AI -- Experiment Run Results
  Dataset : 6,000 rows | 13 features | 4 classes
  Model   : DP Random Forest (IBM diffprivlib)
  Trials  : 3 runs per epsilon (mean +/- std reported)
  Delta   : 1e-05 (fixed)
========================================================


HOW TO RUN
----------
Step 1 -- Train the model:
    python dp_train_test.py
    (Enter epsilon value when prompted, e.g. 0.5 or 1.0)

Step 2 -- Generate all 10 plots:
    python visualize_results.py
    (Enter the SAME epsilon as Step 1)

Step 3 -- View plots:
    start results\plots
    (Opens the plots folder in Windows Explorer)

Or run both at once (Windows PowerShell):
    echo "0.5" | python dp_train_test.py
    echo "0.5" | python visualize_results.py

COMPARISON SUMMARY (All 3 Runs)

| Epsilon | Privacy  | Sigma  | DP Accuracy      | Drop   |
|---------|----------|--------|------------------|--------|
|   0.5   | HIGH     | 7.0318 | 84.47% +/- 3.44% | 15.44% |

Key Takeaways:
  1. Epsilon badhao -> Sigma ghata -> Accuracy badhi (clear tradeoff)
  2. e=0.5 to e=0.7: +1.78% accuracy, sigma 7.03 -> 5.17
  3. e=0.7 to e=1.0: +2.14% accuracy, sigma 5.17 -> 3.73
  4. Variance consistently drops as epsilon increases (more stable)
  5. Analytic GM sigma is used (valid for ALL epsilon values)
     Classical formula would give sigma=9.68 for e=0.5 (38% over-noisy!)
